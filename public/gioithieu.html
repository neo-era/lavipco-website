Website LAVIPCO

Nền tảng thương mại điện tử kết hợp giới thiệu doanh nghiệp cho Công ty TNHH Kỹ Nghệ Lâm Việt Phát — chuyên đèn tín hiệu giao thông, chiếu sáng đô thị thông minh, hạ tầng điện và Smart City.

Xây dựng trên nền tảng web hiện đại, tối ưu tốc độ, chuẩn SEO, bảo mật và quản trị nội dung linh hoạt.

Next.js 14 TypeScript Tailwind CSS Prisma + PostgreSQL Auth.js Vercel

1. Giới thiệu chung

Website LAVIPCO là một ứng dụng web full-stack vừa bán hàng online vừa giới thiệu năng lực doanh nghiệp. Toàn bộ nội dung, sản phẩm, đơn hàng và cấu hình được quản lý qua một Admin Panel tích hợp.

  • Trưng bày sản phẩm thiết bị chiếu sáng, đèn tín hiệu, phụ kiện, hệ thống điều khiển.
  • Giới thiệu dịch vụ kỹ thuật và portfolio dự án đã thực hiện.
  • Hỗ trợ giỏ hàng, thanh toán, theo dõi đơn hàng, yêu cầu báo giá và liên hệ tư vấn.
  • Quản trị toàn bộ nội dung và vận hành mà không cần lập trình.

7. Kiến trúc & bảo mật

Kiến trúc

  • Server Components ưu tiên — render phía server, tải nhanh, ít JS gửi xuống client.
  • Server Actions cho thao tác dữ liệu (thay vì API route truyền thống) — gọn, có sẵn bảo vệ CSRF.
  • ISR (Incremental Static Regeneration) + revalidate — trang tĩnh nhanh, tự cập nhật khi admin sửa.
  • CMS nội dung — text/ảnh trang chủ & giới thiệu lưu trong DB, có fallback mặc định.

Bảo mật

  • Phân quyền (RBAC): USER / STAFF / ADMIN; mọi action admin kiểm tra quyền.
  • Validate đầu vào bằng Zod ở mọi form & action.
  • Rate limit các endpoint nhạy cảm; khoá tài khoản chặn đăng nhập.
  • Security headers (CSP, HSTS, X-Frame-Options...) + HTTPS bắt buộc.
  • Sanitize HTML khi hiển thị nội dung blog.
  • Tuân thủ Nghị định 13/2023/NĐ-CP về bảo vệ dữ liệu cá nhân.

8. SEO & hiệu năng

  • Metadata động cho từng trang (title, description, Open Graph).
  • sitemap.xml + robots.txt tự sinh.
  • Dữ liệu có cấu trúc Schema.org / JSON-LD (Organization, Product...).
  • Tối ưu ảnh qua next/image, lazy-load, định dạng hiện đại.
  • URL thân thiện (slug tiếng Việt không dấu), tốc độ tải tối ưu nhờ SSR/ISR + CDN.
